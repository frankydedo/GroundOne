# Leviathan 2023 – Fast Inference from Transformers via Speculative Decoding

**Raw file**: `raw/local_inference/Leviathan 2023 - Fast Inference from Transformers via Speculative Decoding (arXiv 2211.17192)_ingested.pdf`

## Overview
Autoregressive decoding of K tokens takes K serial runs of the model. **Speculative decoding** lets a small, cheap **approximation (draft) model** M_q propose γ tokens, and the large **target model** M_p checks all of them **in one parallel forward pass**. A new rejection-sampling rule, **speculative sampling**, accepts or corrects the guesses so that the output distribution is **exactly** that of the target model (§2.3, App. A.1). No retraining or architecture change is needed. On T5-XXL (11B) the method gives **2×–3×** lower latency than the T5X implementation with identical outputs (abstract, §4.1). The premise is explicit: inference from large models is usually bottlenecked by **memory bandwidth and communication, not arithmetic**, so spare compute can be spent on parallel verification (§1).

## Key Insights
1. **Algorithm in plain words (§2.1, Alg. 1).** Run M_q autoregressively for γ steps; run M_p once on the prefix plus all γ guesses, which yields γ + 1 next-token distributions in parallel; accept guess x if q(x) ≤ p(x), otherwise accept it with probability p(x)/q(x); at the first rejection, resample from norm(max(0, p − q)). Each iteration produces **at least one and at most γ + 1** tokens, so it is never slower in serial target calls than plain decoding.
2. **Acceptance rate α (§3.1–3.2, Theorem 3.5).** β = Σ_x min(p(x), q(x)) = 1 − D_LK(p, q), a symmetric divergence; α = E(β). Under an i.i.d. assumption, expected tokens per iteration = (1 − α^{γ+1}) / (1 − α) (Eq. 1).
3. **Walltime and cost (§3.3–3.4, Theorem 3.8, 3.11).** With c = time of one M_q run / time of one M_p run, the expected walltime improvement is (1 − α^{γ+1}) / ((1 − α)(γc + 1)); any α > c gives some gain (Corollary 3.9). The price is **more arithmetic**: rejected guesses waste computation. Table 1 (c = ĉ = 0): α = 0.8, γ = 5 → **3.69× faster for 1.63× the operations**; α = 0.9, γ = 10 → 6.86× for 1.60×; α = 0.6, γ = 2 → 1.96× for 1.53×. Memory reads of the target's weights and [[KV Cache]] fall by the same factor as serial calls (§3.4).
4. **Measured speedups (Table 2; T5-XXL 11B on one TPU-v4, batch 1).** English–German: T5-small draft, argmax (temp 0), γ = 7, α = 0.75 → **3.4×**; standard sampling (temp 1) α = 0.62 → 2.6×. CNN/DM summarisation: 3.1× (temp 0) and 2.3× (temp 1). Larger drafts raise α but also c: T5-large gives α = 0.82 yet only 1.7× (temp 0, EnDe).
5. **Empirical α (Table 3, §4.2).** Drafts about two orders of magnitude smaller than the target reach α = 0.5–0.9 (e.g. LaMDA 137B with a 100M / 2B / 8B draft: 0.61 / 0.71 / 0.75 at temp 0). Even a bigram model gives α ≈ 0.2 on EnDe and, with c ≈ 0, a 1.25× speedup at γ = 3. Sharper (lower-temperature) distributions give higher α. Measured c was always below 0.05 for their drafts (§3.3); c = 0.11 for T5-large (App. A.3).
6. **Limitation (§6).** Latency is bought with extra computation, so the method does not help when compute is already saturated. An independent implementation (Chen et al. 2023) reported 2–2.5× on Chinchilla 70B (§5).

## Relevance to GroundOne
- **The generative alternative still pays decode.** Speculative decoding is the strongest *output-preserving* way to speed up a generative judge: it shortens the serial decode loop but cannot remove the prefill, and each iteration still needs at least one target pass. A [[System One Models|System One]] removes the loop altogether. On the [[Prefill and Decode]] cost model, speculative decoding divides the $K\cdot n\cdot t_{dec}$ term by at most (1 − α^{γ+1})/((1 − α)(γc + 1)); GroundOne's design (b) has no such term ($T_{S1}\approx\mathrm{prefill}$). Speculative decoding is therefore the fair "what if the baseline were optimised" counterpoint, and the thesis should mention it when it reports GroundOne's speed advantage.
- **Where it would and would not narrow the gap.** The terse judge decodes only a few tokens per sentence, so there is little to speculate. The verbose (rationale) judge spends most of its time decoding, so a 2–3× speedup on that part would shrink GroundOne's ≈6× advantage at K ≥ 14 ([[GroundOne Results]]) substantially but not close it, since the judge would still decode. This is a qualitative argument; the thesis did not run speculative decoding.
- **Illustrative fit on the thesis hardware (arithmetic, not a measurement).** A natural draft/target pair on the M4 would be Qwen2.5-0.5B drafting for Qwen2.5-3B (same tokenizer family). From the thesis's own MLX decode times (≈7 ms vs ≈37–42 ms per token, [[Prefill and Decode]]), c ≈ 0.17–0.19, far above the paper's < 0.05, because 0.5B is only about 6× smaller than 3B rather than ~100×. With an *assumed* α = 0.8, Theorem 3.8 gives about 1.9× (γ = 3, c = 0.18). The paper's spare-compute premise roughly holds on the M4: one decode step costs about as much as prefilling 17–21 tokens there, so verifying γ + 1 ≈ 4–6 tokens in one pass stays close to the cost of one step.
- **Same trick as GroundOne's one-pass readout.** The verification step reads next-token distributions at γ + 1 positions from **one** forward pass, which is exactly what GroundOne's design (b) does at the K " Verdict:" markers ([[Letter-Token Readout]]). Both exploit the same fact: at batch 1 a pass over a few extra positions costs about as much as a single decode step.
- **Energy.** Speculative decoding lowers latency at the cost of 1.1–1.6× more arithmetic in Table 1. The paper does not measure energy, but in line with the thesis's power-vs-energy findings ([[Energy of LLM Inference]]), a faster judge is not necessarily a cheaper one in joules.
- **No effect on accuracy or calibration.** Because the output distribution is unchanged, a speculatively decoded judge has the same verdicts and verbalised confidences as the plain one; GroundOne's accuracy comparisons with the judges (B0, B0d) and the single-token control B2 would not change.
