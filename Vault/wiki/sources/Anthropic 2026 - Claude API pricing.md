## Key Insights
- Standard list prices per million tokens (input / output), accessed 2026-10-19: Claude Fable 5.1 $10 / $50; Opus 5.5 $4 / $20; Sonnet 5.5 $2 / $10; Haiku 5.5 $0.10 / $0.50 for prompts up to 100K tokens ($0.50 / $2.50 above).
- Prompt caching (cache hits 2.5–10 % of the input price), batch discounts and a 1.1× multiplier for US-only inference also exist.
